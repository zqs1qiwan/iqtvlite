# Android TV IPTV UI/UX 重构设计 v1

日期：2026-11-18。任务 t3，designer。Captain 已确定本轮实施主 Compose 工程 A+B：完整观看、浏览、设置与异常闭环；C 品牌资产扩展后置。设计依据为 [当前 PRD](PRD.md)、[源码勘察](UI_UX_INSPECTION.md)及 tivimini 已有操作；采用 TiviMate 风格的全屏观看与层级导航思路，并非宣称已对当前 TiviMate APK 做视觉测量。

本文为实现规范，不是实现通过或视觉验收证明。当前模型不支持图像读取；尚需实现后的实际设备截图、遥控器操作与播放证据。

本轮以 [验收矩阵 A01–A14](UI_UX_ACCEPTANCE.md)为边界，A09所有基础设置必须真实生效并在进程重启后持久化，不作为延期项。两处条件明确如下：A03按出厂默认“恢复上次频道=开”验证；A09将其关闭后，启动应播放当前列表第一频道，重新打开则恢复最近一次实际成功播放的频道。A06历史节目OK在默认“直接回看”下启动回看；设置为“确认后回看”时，第一次OK只打开确认，第二次确认才播放，取消/Back保持原直播或回看及节目焦点。当前/未来节目永不触发回看。验收兼容条款中的“已保存源时恢复上次频道”按此开关条件执行。

## 1. 信息架构与体验原则

用户启动后尽快观看电视。保留全屏视频和 tivimini 默认操作：上下换台、左侧频道、右侧设置、OK 信息。视频不因浏览频道、节目或设置而暂停；选择频道/回看才改变播放。节目单与设置独立入口、互斥展开。

```text
启动
 ├─ 未有有效源/频道 → 源配置（二维码 + 手动输入）→ 校验/导入 → 全屏播放
 └─ 已配置 → 缓存列表 + 上次频道（关闭恢复时为第一频道）→ 后台刷新
全屏播放
 ├─ 左 → 频道层 ─左→ 分组层 ─OK→ 该组频道层
 │               └右→ 该焦点频道节目层 ─右→ 日期层
 ├─ Guide键（有时）→ 当前播放频道节目层
 ├─ 右 / Menu → 设置根层 → 子设置/选择层
 ├─ OK → 换台信息条
 └─ 数字 → 输入缓冲 → OK或1.2秒 → 全局频道
播放异常 → 自动恢复 → 成功继续 / 失败操作面板
```

基础状态：PlaybackMode = Live / Catchup；Panel = None / Channels / Groups / Programs / Dates / Settings(path) / PlaybackFailure；InfoVisible 独立但普通侧栏出现时隐藏。最高层确认对话框、源选择页和文本输入只处理自己的按键，不向播放层透传。一次物理按键只触发一次动作。

## 2. 布局、文字与颜色 token

全部布局尺寸为 dp，文字为 sp；获取实际 Compose 可用宽度 W，不用物理像素替代 dp。`panelWidth = min(360.dp, W / 3)`，容器锚定屏幕左/右边缘，高度铺满；所有子层保持该宽度，切换层时替换内容，不横向追加列。W=960dp 时宽320dp；W=1280dp 时宽360dp。任何 minWidth 都不得覆盖 W/3 上限。目标 TV 逻辑宽度至少960dp；更窄测试窗仍遵守上限，通过换行和减少同屏行数保证可操作。

| 项目 | 规范 |
|---|---|
| 配置页安全边距 | 横向48、纵向32；侧栏可操作内容距屏边24，距上下边24 |
| 间距梯度 | 4 / 8 / 12 / 16 / 24 / 32 / 48 |
| 侧栏内容区 | 左右24；列表行内左右12；分隔8；聚焦边框不改变布局 |
| 字号 | 页面标题28sp，中层标题24sp，频道/设置项20sp，节目正文18sp，辅助/时间16sp；主频道信息28sp，数字缓冲36sp |
| 行高 | 按字重/字号约1.3–1.4；中文优先常规/中等字重，正文不使用细体 |
| 项高 | 普通设置/分组最少56dp；频道含当前/下一节目最少112dp；节目最少88dp；允许内容自然增高，禁止固定高度裁掉文字 |
| 圆角 | 侧栏内卡片/按钮12dp；面板外轮廓不靠大圆角损失内容；成功台标无圆角裁切 |
| 背景 | page #101316；panel #161C21，alpha 0.96；视频外区不加全屏暗幕，维持亮度 |
| 文字 | primary #F5F7F8；secondary #BCC7CE；disabled #84919A，禁用仍可读 |
| 焦点 | fill #30454D + 2dp #A8E8D4 描边 + 白文字；不放大整行、不挤动列表 |
| 当前播放/选中 | #76D7BB 图标/4dp左标记，配“播放中”文字或喇叭图标；与焦点边框同时显示 |
| 错误/成功 | #FFB4AB / #76D7BB；必须伴随图标或文字，不只依赖颜色 |
| 动画 | 面板160ms入/140ms出，层切换120ms淡入，焦点100ms；不循环闪烁、无大范围模糊 |

透明面板上的文字按最亮/最暗视频背景验证对比；正文目标至少4.5:1，大字3:1。若设备合成后不达标，提高面板不透明度，不能靠文字阴影补救。视频不缩放到小窗；右侧至少2/3保持可见。

成功加载 logo：ContentScale.Fit，原始透明度，无背景卡片、描边、圆角clip；频道行48×32dp，信息条80×48dp。下载中保留槽位，失败/无地址用通用TV图标加可访问说明，不把频道名首字母伪装成已下载台标。

## 3. 全屏播放器与信息条

### 默认遥控器映射

| 按键 | Live且无面板 | Catchup且无面板 |
|---|---|---|
| 上 / 下 | 全局频道上一项/下一项，首尾循环 | 显示回看信息 |
| 左 | 频道层 | 后退10秒；连续按住按现有30/60/300秒阶梯加速 |
| 右 | 设置根层 | 前进，同上；不越过节目时长 |
| OK/Enter | 显示/刷新信息条5秒 | 显示/刷新回看信息5秒 |
| Menu | 设置根层 | 设置根层 |
| Guide（存在时） | 当前频道节目层 | 当前直播频道节目层 |
| Channel+/−（存在时） | 下一/上一频道 | 提示“先返回直播后换台” |
| MediaPrevious（存在时） | 回上一观看频道 | 提示“先返回直播后换台” |
| Back | 信息条可见则关闭；否则2秒内再按退出 | 信息条可见则关闭；否则首次提示，再按返回直播 |
| 0–9 | 进入数字缓冲 | 不换台，提示“回看中，可从设置返回直播” |

自定义只改变 Live无面板的映射，详见设置；面板内方向键和Back始终用于导航。换台按住重复最多每250ms提交一次，切台请求按最新一次生效，旧加载/错误不得覆盖新频道。双Back计时只在该状态且无其他操作时有效；换台、打开层、关闭信息条后重置，防止误退出。

信息条位于底部，外边距左右32、下24，内部24，宽W−64，高度随内容，直播目标约152dp。第一行logo + 全局编号/频道名 + 可选“播放中/回看中”；第二行“正在播放  时间  标题”与进度；第三行“接下来  时间  标题”。节目标题单行截断，不滚动整个信息条。无当前/下一节目分别显示“暂无当前节目信息”/“暂无后续节目信息”。视频参数为次要16sp，不抢占节目宽度；窄屏移至设置的播放信息页。节目单数据来自该频道，不受当前筛选分组影响。

数字反馈位于右上安全区：大字显示完整输入（例如112），下方“确定立即切换”，输入保留到新键或提交。最后一位后1.2秒自动提交；OK立即提交；Back取消并消费本次Back；方向/Menu先取消数字再执行自身动作。重复KeyDown不追加同一位；最多为总频道数位数且至少3位、最多6位，超限保留原值并提示。前导0允许输入，按十进制解释；0/越界显示“没有频道 0/xxx”，2.5秒后收起，保持原频道。有效号码显示目标频道名并切台，信息条使用同一个全局编号。

全局编号定义：ChannelGrouper合并后的顺序、从1起，所有分组过滤保留该号，同组多线路共用一个号；不按当前筛选重新编号。刷新导致频道变化时根据稳定频道标识匹配当前播放和焦点，无法匹配才退回第一频道；相同输入总是对当前已展示列表生效。

## 4. 左侧单层导航

每层都有24sp标题、16sp上下文、内容列表与16sp底部按键提示。所有层只显示一个面板。侧栏没有自动关闭计时，供用户安心浏览。左侧层的根是Channels；Groups是其筛选子层，Programs是内容子层，Dates是Programs子层。

| 层 | 布局与OK | 左/右 | Back与焦点恢复 |
|---|---|---|---|
| Channels | 标题“频道”，副标题当前组及数量。每行编号/名称、透明logo、“正在…/接下来…”各一行；当前播放有持久标记。OK切台并关闭面板、显示信息条 | 左→Groups，右→焦点频道Programs；不切台 | Back关闭回视频。下次打开优先当前播放频道（所属组不包含时自动“全部”），保证用户能找到当前频道 |
| Groups | 标题“频道分组”；第一项“全部”，其后分组名/数量；当前筛选用勾选。OK选择该组并回Channels | 右等同选择当前分组进入；左留在本层 | Back取消未提交的浏览，回Channels原焦点。进入新组优先该组播放频道，否则该组上次浏览频道，否则首项 |
| Programs | 标题为频道名，副标题日期；行含时间、标题、直播中/可回看/已结束/未开始。OK按节目行为规则处理 | 左回Channels；右→Dates | Back与左相同。保存频道焦点、滚动位置；若Guide直接进入，本层Back关闭视频，不凭空进入频道层 |
| Dates | 日期垂直列表，“今天”明示；当前日期带勾选。OK选日期回Programs并聚焦该日当前节目或首项 | 左取消回Programs；右留在本层 | Back取消；恢复原节目焦点/滚动位置，不能改变日期 |

频道首尾上下循环，分组/节目/日期上下在边界停留。频道层不添加可抢占左右键的嵌套按钮；上下顺序线性。标题不是隐藏焦点目标。空列表提供一个明确按钮：频道空“重新加载”，节目加载失败“重试节目单”，没有EPG配置“配置EPG”，数据有效但无节目则“返回频道”；该按钮可聚焦，保证右进空页后不丢焦点。若没有日期，右键留在Programs并提供“暂无可选日期”的非阻断反馈。

节目选择规则：历史且具备有效catchup → 默认直接播放回看；选“确认后回看”时显示节目名/起止时间与“开始回看/取消”，初始焦点为“开始回看”，Back等同取消并恢复该节目焦点；历史不可回看不显示“可回看”，OK保持页面并提示原因；正在播放节目OK切到该频道直播并关闭面板；未来节目OK显示“节目尚未开始”，不制造预约功能。回看结束自动返回对应直播并显示“节目已结束，已返回直播”。

浏览不改变当前播放：例如播放3、焦点在8，3保留播放标记，8显示焦点框。节目标题较长：静止截断；仅当前焦点标题等待800ms后慢速单次滚动，离焦复位，关闭系统动效时保持静止。

## 5. 独立右侧设置

设置根与所有子页保持同一panelWidth，层内替换内容。进入根默认焦点上次使用项，首次为“源配置”；Back或左回父层，根Back/左关闭；右进入可进入的子项，OK同进入。选择项单选值OK即保存并返回父页，Back取消未提交选择；保存后在原行显示当前值。所有用户偏好持久化到Prefs/等价存储，进程重启后保留。

| 根项目 | 子内容/默认值 | 生效与失败规则 |
|---|---|---|
| 源配置 | 打开全屏二维码/输入页；返回恢复此设置项 | 有效新列表导入后才替换已保存源/缓存/当前播放；失败保留旧源，输入草稿可继续编辑 |
| 上一频道 | 显示上个频道名；无历史时禁用并解释 | 直播下切换当前与上一个不同频道；仅成功开始播放后更新上一频道历史，刷新和线路切换不算新频道 |
| 返回直播（仅回看时） | 直接回对应频道直播 | 清除回看状态，显示信息条 |
| 遥控器 | 动作映射、恢复默认 | 见下文；仅Live全屏生效 |
| 启动播放 | “恢复上次频道”开关，默认开 | 关时启动播放列表第一频道；缓存存在先缓存播放，无缓存走源加载状态，不强迫重新填地址 |
| 刷新与缓存 | 列表策略、EPG策略、立即刷新列表、立即刷新EPG、最近成功时间 | 刷新不清空可用缓存；保留当前播放，后台失败提供可见结果与重试 |
| 节目选择 | “直接回看”（默认）/“确认后回看” | 仅影响可回看的历史节目；不把无catchup节目变成可播放 |
| 源选择（多线路时） | 自动/各线路及已测延迟；当前线路勾选 | 行进显示探测状态；失败标“不可用”，选源失败可返回自动；此处不改变频道编号 |
| 播放信息 | 分辨率、格式、当前线路、播放状态 | 只读，不出现无法操作的假按钮 |
| 检查更新 | 当前版本与检查结果 | 明确“检查失败/暂无更新/可更新”；取消回原设置焦点，首次配置前不弹自动更新打断 |

刷新策略选项：列表默认“启动时 + 每6小时”，其他“仅启动时”“仅手动”；EPG默认“启动时 + 每6小时”，其他“每天首次启动”“仅手动”。缓存总是先用；启动刷新在播放器建立后后台执行。周期按最近成功时间计算，失败不更新时间；自动失败后至少5分钟退避，避免重试风暴。用户立即刷新不受退避影响；同类请求进行时合并/禁用重复提交并显示“更新中”。EPG不配置时相关项说明“尚未配置EPG”。策略变更立即影响后续调度，不中断播放；源变更重新计算对应源的缓存与成功时间。

遥控器动作：上一频道、下一频道、上一观看频道、频道列表、节目单、设置、信息条；显示当前按键的中文名称。默认沿用第3节；设置入口Menu保留为不可改的安全入口。选择动作→按键捕获子页，提示“按下要使用的按键”，Back取消；只接收单次KeyUp配对，不捕获长按/组合键。

可分配：四方向、Channel+/−、Guide、MediaPrevious及设备发送的其他已识别普通功能键。禁止：Back、Home、Power、音量、数字0–9、OK/Enter、Menu；这些键保持基础职责。键已有其他动作时拒绝保存，显示“此键已用于[动作]，请选择其他键”，原映射不改变。允许某动作清空自定义后回默认，恢复默认需确认；操作完成逐条显示实际映射。界面不声称拦截系统键。配置只在Live无面板有效，回看快进及面板导航不变；五键遥控器仍可通过Menu设置中的“上一频道”操作。

## 6. 首次配置与重新配置

全屏页面：标题“添加播放源”，小字“手机与电视连接同一局域网”。左侧约40%为白底二维码、完整局域网URL与三步说明；右侧约60%为“直播源地址（必填）”“EPG地址（选填）”和主按钮“保存并播放”。保留PRD测试预填且允许完全改写。QR不是焦点项，URL可读/可手动输入，不用TV端复制作为必要步骤。

首次焦点在“保存并播放”，方便直接使用预填测试；上键可到EPG再到直播源，Tab/ShiftTab同序。字段只读浏览态按OK进入系统输入法；输入法Back先关闭键盘并恢复该字段焦点，再一次Back退出配置。文字输入中的左右移动光标不触发页面操作。每个字段独立行内错误，长地址横向滚动仅在编辑中；浏览态可显示域名+末段，编辑时完整值可见。

首次配置Back退出应用遵循双Back；从设置进入则Back回原播放与设置焦点。请求进行中Back取消当前请求并回可编辑状态，旧请求结果被丢弃；播放启动成功后不允许旧请求覆盖新状态。

| 配置状态 | 页面表现与可用动作 |
|---|---|
| Idle | QR和字段可用，主按钮可聚焦 |
| LAN启动/QR生成 | QR槽位状态文字，手动输入仍可用 |
| LAN失败 | “无法启动手机配置”+“重试手机配置”按钮，显示简短原因；手动方式始终可用 |
| Loading | 主按钮“正在加载频道…”，字段锁定，进度不伪造百分比；提供“取消”焦点目标 |
| Invalid URL | 字段下“请输入完整的http或https地址”，焦点返回该字段；不发请求 |
| HTTP/网络失败 | 常驻错误卡“无法加载播放源”+可读原因/状态码，主动作“重试”，副动作“修改地址” |
| Empty/解析失败 | “此地址未包含有效频道”，保留输入、旧缓存/源；可修改/重试 |
| Success | “已导入N个频道”短反馈，进入播放；EPG独立后台加载，不阻塞首台 |

手机表单按现有字段推送，成功接收后电视显示“已收到手机配置，正在加载…”，走同一验证/保存/播放状态机；不要另写一条跳过错误/缓存保护的路径。推送未提供EPG字段时保留草稿原值，显式提交空EPG才清空；当前进行的请求由最新一次推送替代。局域网服务生命周期跟随配置页，离开后正常关闭。

## 7. 播放与数据状态反馈

| 状态 | 信息与动作 | 焦点规则 |
|---|---|---|
| 首台/换台加载 | 延迟300ms才显示右下“正在加载[频道名]…”；信息条立即显示频道；READY/首帧后收起 | 不抢焦点；仍可换台/开频道/设置 |
| 自动恢复 | 显示“连接中断，正在重试 1/3…”；只对当前播放会话生效 | 不打断已打开的面板 |
| 恢复耗尽 | 右侧失败面板“暂时无法播放[频道名]”，可读原因（如服务返回503）；按钮“重试”“选择频道”“源配置” | 无其他面板时自动显示，默认“重试”；用户已有面板则先标记失败，关闭后显示，禁止抢走已有焦点 |
| 连接长期无结果 | 单次准备12秒未READY视为该次超时；最多3次恢复后进入失败终态，不能只隐藏loading | 用户可立即换台，不必等待全部重试 |
| 缓存启动 | “正在使用已保存频道”短反馈；后台成功静默更新 | 不抢焦点；无可用缓存则进加载/源错误页 |
| 列表刷新失败 | 设置行显示“更新失败，已保留原列表”，带“重试”；自动失败仅短提示 | 当前播放不重置 |
| EPG加载/无数据 | 节目页区分“正在加载节目单”“此频道暂无节目单”“尚未配置EPG” | 对应返回/重试/配置按钮均可到达 |
| EPG刷新失败但有旧数据 | 顶部“更新失败，显示上次节目单”与最近成功时间 | 浏览继续，重试入口稳定 |

自动恢复次数包含重新取列表/切线路的实际播放尝试，总计最多3次，每次重新准备最多12秒，阶段间退避800ms；避免现有多层重试叠加为无限循环。网络列表刷新也必须有超时。每次用户主动重试重新开始预算；用户切台/离开回看/配置新源会使旧恢复会话失效。若数据层当前无法给出原因，文案为“连接失败，请重试”，不臆测网络或源站归因。

失败面板Back关闭回视频，保留一个小型“播放失败，按确定重试”的状态条；此时OK重新打开失败面板，Left/Right仍可进入频道/设置。已关闭失败不会按计时自动反复弹出。选择频道打开频道层且Back可回失败面板；选择新台后开始新会话。重试成功清除失败标记与错误按钮。回看失败同样提供“重试/返回直播”，不强迫用户完成双Back。

## 8. 焦点与事件实现约定

1. 将浮层导航作为显式状态栈管理；Back只弹一层，不同时触发Activity退出。Activity与Compose只能有一个最终事件所有者；KeyDown方向处理，OK/数字提交按单次事件处理，释放事件消费规则一致。
2. 打开面板后在该页列表项完成布局且滚动到目标后requestFocus，不用任意80ms延迟模拟父子层返回。关闭面板后焦点回播放器的单一遥控器宿主，PlayerView不获得方向焦点。
3. 保存稳定ID与滚动锚点：频道标识、分组名、节目(channelId/start/end)、日期、本层父焦点。列表刷新后ID不存在则使用最近有效序号，不跳隐藏页面；空集合聚焦可操作空态按钮。
4. 隐藏/退出动画层立即停止参与焦点与事件；动态源选择行消失时焦点回其前一个有效项；不能掉到透明页面。
5. 焦点更新不写Prefs、不触发播放；选中/正在播放依据真实已选择会话，播放成功状态另有反馈；加载中的目标标“连接中”，失败后不伪称“播放中”。
6. 列表焦点保持在可视区中部，尽量预留上下各一行；长按滚动节流且不卡住返回；所有按钮至少56dp，TalkBack描述包括频道号、名称和播放/焦点以外的语义状态。

## 9. 开发切片与设计对照用例

实施顺序：全局编号/状态模型→视觉token/透明logo→单层左侧导航→Now/Next信息/数字反馈→设置与持久化→配置错误/缓存/恢复终态→目标机回归。沿用现有UA/IPv4/gzip/解析/缓存基础，修改播放编排时保证请求兼容性仍生效。无需新首页、账户或第二套播放器。

| 路径 | 设计预期与需留证据 |
|---|---|
| 清数据→首次配置→手动播放 | QR与两字段同时显示、纯方向+OK可达；首台有真实播放证据 |
| 手机扫码→提交其他源 | 收到推送反馈、能加载并保存；失败仍可编辑，不能只验QR显示 |
| 非“全部”分组→选频道→数字相同编号 | 分组/信息条/数字目标一致；有不同焦点与播放标记的截图 |
| 左频道→右节目→右日期→Back→Back→Back | 每次只退一层，焦点恢复原日期/节目/频道锚点，最后回视频 |
| Guide直接节目→Back | 直接回视频，无额外频道层 |
| 设置→改按键→重复映射→重启 | 冲突阻止保存，原按键保留；有效偏好重启后生效，Menu可救援 |
| 播放3、浏览8 | 3持续播放标记、8焦点边框，不因浏览自动切台 |
| 坏源/空列表/EPG失败/流503/断网缓存 | 各自有可辨状态与遥控器恢复动作；旧源/列表不被失败请求覆盖 |
| 320dp面板、长中文、亮色视频 | 所有层≤W/3；焦点框完整，16sp辅助字可读；成功logo透明边缘完整 |

本设计交付不代替独立验收；截图能力或目标设备不可用时须逐项标记未验证。最终结果应对照 [源码勘察](UI_UX_INSPECTION.md)中已知偏差逐项销项，而非仅报告“界面已美化”。
