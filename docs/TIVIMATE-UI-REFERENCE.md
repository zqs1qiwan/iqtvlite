# TiviMate UI 设计参照（真机截图 + 官网调研）

> 2026-11-17，设备 TR100-G9，TiviMate v2.1.5（用户装的 apk）
> 官网 https://tivimate.com/ 调研 + 真机操作截图

## 1. 核心结论：满屏播放优先，UI 按需浮出

**默认状态 = 纯满屏视频，没有任何 UI**（真机截图 tm-real3.png 只有视频画面 + 视频自带台标）。
这与我们当前实现（列表常驻占半屏）完全相反 —— 这是需要修正的根本问题。

## 2. 浮层结构（按左键后截图 tm-left.png）

屏幕是分层的，视频始终铺满底层：

```
┌──────────────────────────────────────────────────────────┐
│ 视频全屏铺底（1920x1080，亮度正常可见）                      │
│ ┌────────────┬─────────────┐                              │
│ │频道列表浮层 │ 节目时间浮层 │     ┌────────────────┐        │
│ │(半透明黑)   │ (半透明黑)   │     │当前节目信息卡   │        │
│ │20 湖南卫视4K│ 08:40 节目35 │     │最好的安排(36)   │        │
│ │  最好的安排 │ 09:32 节目36◄高亮 │ 09:32-10:25 37分钟│       │
│ │  ▬▬▬▬░░░   │ 10:25 节目37 │     └────────────────┘        │
│ │21 浙江卫视4K│ ...          │                              │
│ └────────────┴─────────────┘                              │
└──────────────────────────────────────────────────────────┘
```

- **左侧频道列表浮层**：约 30% 宽，半透明黑底。每行 = 频道号 + Logo + 频道名 + 当前节目名 + 进度条
  - 选中行：蓝色高亮 + 右侧播放小三角
- **中间节目时间浮层**：约 25% 宽，半透明黑底。列出该频道当天节目（时间 + 名称），当前节目高亮
- **右上信息卡**：当前节目名 + 时间区间 + 进度条 + 剩余分钟
- 所有浮层都是**半透明**（视频依然透出），圆角、无突兀边框

## 3. 遥控器交互（官网 + 实测）

| 按键 | 行为 |
|---|---|
| OK | 打开/关闭频道列表浮层 |
| 左键 | 打开分组列表 |
| 右键 | 打开 EPG 网格 |
| 上/下 | 换台（播放中）/ 移动焦点（列表中）|
| 返回 | 关闭浮层，回满屏 |
| 长按 OK | 当前频道选项菜单 |

## 4. 秒播要求（用户明确）

- 导入 `iptv.laobaitv.net` 一次后，**启动时自动播放上次的频道**（秒播）
- 不需要每次手动刷新；缓存优先，网络后台刷新
- 启动即进播放，浮层默认隐藏

## 5. 我们要改造的方向

1. `activity_main.xml`：PlayerView 改为 match_parent 铺满，其余 UI 全部做成浮层（默认 gone）
2. 启动时直接自动播放上次频道（从缓存 + 保存的 last channel id）
3. 频道列表浮层：左侧半透明，TiviMate 行样式
4. 顶部信息卡：换台时短暂浮现（3-5s）后消失
5. OK/方向键控制浮层显隐；返回键优先关闭浮层
6. EPG 做成右侧浮层
