# 1.7 — 真·分层视差海报卡（前景/背景双层素材）

> 2026-11-17

## 1. 真分层视差（补齐 Apple TV 保真度缺口）

之前海报卡的"视差"只是几层纯色 View 的位移，没有真实素材分层。本轮做到**真分层**：

- `LayeredPoster.kt`：用 Coil 加载频道 Logo 后，**从同一张图生成模糊背景版**
  （下采样到 16×16 再放大 = 廉价模糊，API 28 可用，无需 coil-transformations 额外依赖，压暗 140 alpha）
- 前景层 = 清晰 Logo；背景层 = 模糊 Logo + 光晕叠加
- **差动视差**：聚焦时前景 Logo 放大 20% + 上浮 14dp，背景模糊层放大 10% + 反向位移 8dp + 变暗，
  文字层上移 6dp —— 三个真实图层按不同位移运动，产生景深

真机截图确认：海报卡背后透出各频道色调的模糊光晕，聚焦时有明显层次感（不再是纯色卡）。
