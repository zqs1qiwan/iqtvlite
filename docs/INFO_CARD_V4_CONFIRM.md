## 1. 信息卡布局（已确认 · 按此实现）

```
┌──────────────────────────────────────────────────────────────────────────┐
│  ┌────────┐                                          HD  帧数  5.1       │ ← 右上紧凑徽标（分辨率·帧率·声道）
│  │        │                                                              │
│  │  LOGO  │   23. 东方卫视                    节目名（单行省略）          │ ← 序号+台名；台名下不再写 MPEG-L2
│  │  大    │   本台分组小字                   ━━━━━━━━━░░░  3dp 进度      │ ← 台名下=本台分组；右侧节目+进度
│  │        │                                                              │
│  └────────┘   ┌──┐ ┌──┐ ┌──┐ ┌──┐                                        │ ← 最近观看 4 个：横向仅排列 logo
│               │1 │ │2 │ │3 │ │4 │   左右键聚焦 / OK 跳台                 │   无 logo 时显示文字（回退）
│               └──┘ └──┘ └──┘ └──┘                                        │
└──────────────────────────────────────────────────────────────────────────┘
```

**确认要点**
- 右上徽标三项：`分辨率(HD/FHD/4K/SD)` · `帧数(fps)` · `声道(5.1/2ch)` —— 紧凑一排、不单独分行、不换行。
- 台标下：**序号. 台名** + **本台分组小字**（不是编码、不是 MPEG-L2）。
- 右侧：节目名单行省略 + 起止/剩余 + 3dp 进度。
- 底部：**最近观看 4 个频道**，横向只排 logo；无 logo 显示文字；LEFT/RIGHT 聚焦、OK 跳台。
- 卡片高度收紧（目标 ≤240dp），无硬边框、无蓝框、Flat 风格。
- 播放台标识：**变色** —— 焦点/确认态统一使用 logo accent 蓝 **`#2F6BFF`**（浅底 `#2F6BFF22` + 白色加粗台名/文字，或蓝色高亮条），不用「▶ … 播放中」文字。
- **全局规则（用户明确）**：所有"焦点确认后"的变色都用这个 `#2F6BFF` —— 包括选台列表焦点行、最近观看 4 logo 聚焦、设置项焦点、信息卡最近观看聚焦、数字 OSD 确认态。不再是之前的白色浅底 `#FFFFFF14`，改用品牌蓝。

## 2. 选台列表（用户反馈 bug，逐条修）

| 用户现象 | 期望 |
|---|---|
| 从当前频道打开列表，闪到开头又回到当前台 | 直接定位当前台，无闪动、无回开头 |
| 焦点高亮不出现，上下移动后才出现 | 打开即高亮当前/焦点台 |
| 分组不点击也不进入 | 点分组后右侧立即显示该组频道 |
| 从分组进来选台应从头开始 | 进入分组后聚焦该组第一台 |
| 从「全部频道」按 → 进入选台：只在翻页，进不去 | → 应进入频道列表；选台不需要翻页 |
| 点台换台后列表跳开头 | 按用户实际操作路径修复并验证（t14 已复现：冷启首开/换台时序，滚动被钳到 0 且未校正） |
| 播放台用「▶ … 播放中」文字 | 改为变色高亮 |

**分组交互核心逻辑（用户明确，必须照做）**
1. **聚焦即展示**：在分组列上下移动焦点，右侧频道列**立即**显示该组的频道（不需点击/OK 确认）——这是"聚焦到即展示"。
2. **右键进入 + 收起分组**：按 → 从分组列进入右侧频道列，同时**分组列自动收起**（showGroups=false），让频道列占满；不再需要翻页。
3. **性能**：分组↔频道切换、列表重组必须**善用缓存**——同一内容版本复用已解析快照/已组合行/logo 内存位图，**不要每次切换都重新加载导致卡顿**。已有基础：LogoLoader 内存缓存、按组 lastFocusedByGroup、分帧揭示；新增的"聚焦即展示"不得退化为每次焦点变化都重解析全量频道/EPG。

- 涉及 PlayerDrawer.kt 的节目单列宽/时间列/EPG 行；真机 dump 验证宽度收紧、聚焦滚动可用、不引入 jank。
