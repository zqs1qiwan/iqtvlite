# TiviMate 选台交互 PRD / 设计金标准（真机实测采集）

> 采集设备：192.168.2.130（Android TV，物理 3840×2160，override 1920×1080）
> 参照对象：`ar.tvplayer.tv`（TiviMate），用户标注"当前最舒服的使用环境"
> 采集时间：2026-11-23 20:40 Asia/Hong_Kong
> 采集方法：uiautomator dump 取文字 + 精确 bounds；全屏播放按 LEFT 呼出选台；DOWN/UP 验证焦点
> **本文件是选台/抽屉交互的权威设计基准；与旧 GOLDEN_SPEC 冲突处以本文件为准。**

---

## 1. 核心交互模型（Gold Standard）

### 1.1 呼出
- **全屏播放模式下按 LEFT** → 呼出选台抽屉（真机验证：`containerPlayerChannels` / `framePlayerChannelsContent` / `containerPlayerChannelsList` 出现）。
- 呼出后**当前播放台即为焦点**，并**位于可视区正中间**。

### 1.2 焦点恒定居中（最关键，真机铁证）
- 屏幕高 1080，中心 y=540。
- 呼出后焦点行 bounds `[0,482][600,604]` → 焦点中心 y=543 ≈ 屏幕中心 540（居中）。
- **按 DOWN 后焦点 bounds `[0,500][480,580]`，按 UP 后仍 `[0,500][480,580]`——焦点 box 完全不动，始终居中**。
- 结论：**上下滚动时焦点固定在屏幕中央，只有列表在它下面滚动**（用户原话："焦点都在中间，只是列表滚动，很丝滑"）。
- 这推翻了历史上所有 "focus-2 / 焦点贴上方 2 行 / focus 距顶≈距底" 的旧基准；正确模型是**焦点绝对居中且静止，列表滚动**。

### 1.3 列表结构（真机 bounds）
- 频道列表可见 8 行，频道号 `tvNumber` + 频道名 `tvChannel` + 节目名 `tvProgramTitle`。
- 频道行 y 坐标：132 / 254 / 376 / 498 / 620 / 742 / 864 / 986（行高约 122px ≈ 81dp）。
- 焦点行在列表第 4 行（y=498-541 的 "浙江卫视4K"），列表项高一致、无分割线。

### 1.4 长按连续滚动
- 长按 UP/DOWN 应一路顺滑滚到两端（顶部 idx0 / 底部末尾），焦点全程不离开中心。
- 反例（已根治的 bug）：长按焦点到 idx53 但可见行钉在 4-13、零位移（t68 实测）。正确行为=列表连续跟随焦点滚动。

### 1.5 抽屉自动收回
- 用户明确："选台会几秒后收回抽屉"。
- 真机观察：连续 dump 操作会刷新计时，8s 仍可见（因 dump 间隔刷新了无操作计时）；设计判定=**无操作若干秒后自动收起抽屉**（具体秒数 TiviMate 约 5-8s，我方既定 7s 语义可对齐）。
- 判定：抽屉打开后静止（无方向键/焦点变化）应在数秒后自动关闭；有操作则重新计时。

## 2. 节目单 / EPG 区域（真机 bounds）
- 用户要求："节目单那部分背景更透明用来与选台区域区分，不用线来分割"。
- 真机 EPG 界面：`containerTvGuideChannelsList` + `vgvChannels`（频道 recyclerView）+ `timeLineBackground`。
- 行与行靠**背景明暗交替**区分，**无任何 1dp 分割线**（我方已删 divider，节目区用静态透明背景 alpha≈0.55 与选台区区分——方向正确）。
- 时间轴：`tvProgramTime` + `tvProgramTitle`，节目进度 `pbProgramProgress`。

## 4. 验证方法铁律（用户强烈质疑假通过后的教训）
1. **先清设备 prefs 污染**：remote_ok=OPEN_DRAWER / remote_updown=CHANNEL_STEP 等早期测试残留会让按键走到错误界面，导致"假通过"。清后再验。
2. **dump + 按键放同一 shell 命令**：PowerShell 在 dump 与按键间处理 >7s 会让卡片/抽屉自动隐藏，按键打到错误界面。
3. **焦点居中判定用数据说话**：dump 焦点行 bounds，算中心 y 是否 ≈ 屏幕中心 540；DOWN/UP 后焦点 bounds 是否保持不变（列表动、焦点不动）。
4. 每条附原始 dump/日志/截图，复现不出如实写"未复现"，未验证≠通过。
