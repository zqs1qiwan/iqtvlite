## 3. 真机验证结论（TR100-G9 / API28 / 1080p）

- 功能：数字 OSD、最近观看（清空后重启仍空）、台标缓存、音轨（单音轨门控）、自动更新（单次刷新/退避）、遥控习惯（即时生效/回看 OK 信息条/Back 退出）、设置滚动、MP2 有声、AAC 不回归、无崩溃——均已真机通过。
- 性能基线（稳 500，D-pad）：**TTFF p50 ≈964ms / p95 ≈1720ms**；分段 **fmt(网络首包)≈560ms 占主体、render≈135ms、dec≈0**。
- 冷启：首帧约 2.8s；首帧后有 ~3.3–3.8s 启动 rebuffer（首秒填充率低致 Loader 补流，与起播档无关）。
- 抽屉：稳态 jank 约 27–40%、90th 60–110ms（历史最好 40.03%/90th 61ms）。

## 4. 已知限制

- **换台提速**：瓶颈在网络组播 join + 首 TS 包 + 首 IDR（fmt 段）。TCP 预连接已证无效；组播预热（默认关实验）与首帧解码预热待设备 A/B。
- **冷启 3.3–3.8s 启动 rebuffer**：与起播缓冲档无关，属首秒吞吐问题。
- **睛彩 117/118/119**：卡缓冲无首帧、无崩溃，疑源地址/多播不可达（非 App 解码缺陷）。
- 多音轨真机切换：测试源仅单音轨，逻辑由 JVM 单测覆盖，真机受限。
