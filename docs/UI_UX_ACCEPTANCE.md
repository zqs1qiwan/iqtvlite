# Android TV IPTV UI/UX 验收标准

日期：2026-11-18。范围依据 [PRD](PRD.md) 与源码勘察 [UI_UX_INSPECTION](UI_UX_INSPECTION.md)。本文件定义后续实现的验收门槛，不代表当前版本已通过。P0 为阻断交付，P1 为本轮核心范围需通过，P2 为条件性检查/视觉收尾。每条检查均应记录版本或 APK、环境、结果与证据；未执行标记“未验证”，不可推定通过。

## 1. 执行环境与判定规则

- 基准环境：Android TV 遥控器（目标 TR100-G9 优先），另用 Android TV 模拟器覆盖可重复操作；至少记录 Android 版本、分辨率/逻辑密度、构建 variant、commit 或 APK SHA。构建环境记录 JDK、SDK 与 Gradle 结果。
- 可用源测试真实首帧与持续播放；另准备失效地址、空播放列表、流返回 503、可用备用线路、断网与有/无 EPG 数据的测试样本。现知 112 号财富天下端点 503，不得作为成功首帧样本。
- 遥控器检查需使用实体遥控器或能注入 D-pad、OK、Back、数字键的 TV 环境；触屏操作不能代替焦点验收。
- 严重程度：P0 阻断主闭环、不可恢复或会误导观看；P1 本轮核心交互/可访问性缺陷；P2 视觉与低风险一致性问题。出现 P0 即不通过；P1 在本轮核心重构范围内应全部通过，若项目明确延期须逐项标记延期，不得宣称全量通过。
- 证据类型分开记录：源码审查、自动化检查、当前工作区构建、模拟器遥控体验、目标真机体验。历史记录仅作为背景，不算本次通过证据。构建成功不等同于 lint 清洁或真机体验通过。

## 2. 验收用例

| ID / 严重度 | 前置条件 | 操作步骤 | 预期结果 / 通过判定 |
|---|---|---|---|
| A01 首次配置 / P0 | 清除应用数据；测试 M3U 与 XMLTV 地址可访问，另准备无效地址 | 冷启动；用遥控器从初始焦点依次到直播地址、EPG 地址、保存并播放；输入/保留地址并确认 | 配置页可见二维码、LAN 推送地址和两个地址字段；焦点清晰可达；成功时进入播放器并有真实视频首帧。失败时页面给出可读且可操作错误，保留输入，可重试/修改；不能仅靠短暂 Toast 作为唯一结果。 |
| A02 手机扫码推源 / P1 | 清除数据或运行中；手机与 TV 在可互通 LAN，扫码端可访问 | 扫码；提交与预填源不同的 M3U/EPG；观察应用 | 推送被接收、当前配置更新并按产品行为开始加载/播放；屏幕可辨识加载与失败状态。仅显示二维码不算通过真实推送。 |
| A03 播放与启动恢复 / P0 | 至少两个确认可播频道；首次配置完成；启动恢复设置可切换 | 验证默认设置为开启；播放频道至真实首帧并持续播放至少 60 秒后退出/重启；关闭启动恢复再重启；重新开启后播放另一频道并重启 | 默认开启时恢复最近成功播放的频道；关闭时启动首台；重新开启后恢复最近成功播放频道。每种设置重启后保持所选值。画面和声音持续正常，无意外退出；恢复失败时错误状态可操作且不会无限 loading。 |
| A04 连续数字跳台 / P0 | 播放列表含至少 112 个合并后频道，112 号目标使用可用流 | 遥控器输入 1、1、2；观察数字缓冲；按 OK 提交；另测等待 1.2 秒自动提交和 Back 取消 | 缓冲期间完整显示“112”；OK 立即提交，静置 1.2 秒按设计自动提交，Back 清空输入且不切台。提交后切到全局第 112 号频道。显示编号、分组过滤、信息条与数字跳台映射一致；无效/越界编号给出明确反馈且维持原播放或说明状态，不误切其他台。 |
| A05 频道浏览与分组 / P0 | 当前播放频道与待选频道不同；列表含多个分组及重复线路合并项 | 左键打开节目单；浏览全部与非首分组；移动焦点但不按 OK；按 Back/OK | 单层侧栏宽度为 min(360dp, 屏幕逻辑宽度的 1/3)，视频仍可见；浏览焦点不改变播放；当前播放标记与焦点样式同时可区分；列表不因分组过滤重编频道号；OK 只选择焦点频道并反馈切换。 |
| A06 节目单层级与焦点恢复 / P1 | 当前频道有当前、未来及历史节目 EPG；节目点击策略可配置 | 默认策略下移动到历史节目并按 OK；切换为“确认后回看”策略，再按 OK 并检查确认弹层焦点；分别确认和取消；对当前/未来节目按 OK；进入日期层后逐层 Back | 默认历史节目 OK 直接回看；“确认后回看”策略首次 OK 仅弹确认，确认后启动回看，取消后关闭确认层并恢复到原历史节目焦点。当前/未来节目不误触发回看。频道→节目→日期为清晰层级；每次 Back 只退一层并恢复进入该层时焦点。 |
| A07 EPG 与信息条 / P1 | 一组频道有 EPG、一组无匹配 EPG | 换台后呼出信息条；检查当前和接下来节目、进度；切到缺 EPG 频道 | 有数据时当前/下一节目和进度对应数据；缺数据时显示明确、稳定的“无节目单数据”等占位，不伪造内容；EPG 刷新失败能与“当前无节目”区分并给出恢复入口或明确状态。 |
| A08 回看 / P1 | 选中频道具有有效 catch-up 参数及历史节目 | 从历史节目启动回看；快退/快进及长按；呼出信息条；Back 返回直播 | 仅在 catch-up 能力有效时生成并播放回看 URL；进度/回看状态可辨；seek 操作响应正确；返回能回直播，且回看失败可重试或退出到直播，不遗留无焦点遮罩。 |
| A09 独立设置与持久化 / P1 | 播放器正常播放；准备至少两个频道及可触发的列表/EPG 更新 | 用遥控器逐项修改换台、上一台、节目单、设置等按键映射；尝试制造按键冲突并恢复默认；启用/关闭启动恢复；更改播放列表与 EPG 刷新时机、节目点击行为；逐项退出设置、杀进程并重启，再重复触发各行为 | 设置与节目单为独立入口，焦点初始可见、可移动；关闭后返回原上下文焦点。冲突映射被拒绝或要求明确解决；恢复默认实际恢复默认值。每项设定在重启后仍显示所选值且对应行为生效：上一台回到先前频道、启动恢复按设置执行、刷新按所选时机触发、节目点击行为遵循选项。操作显示进行中/成功/失败反馈。范围内任一项未实现或未持久化即失败，不能以静态控件或延期备注充当通过。 |
| A10 播放失败与恢复 / P0 | 配置可用列表，目标流 503；另准备可用替代线路；再测试无替代线路 | 切到 503 流；等待自动恢复结束；使用重试、换台、重新配置等动作；重复断网 | Loading 有明确超时/完成；恢复耗尽呈现常驻可读错误及遥控器可达动作；重试后状态更新；替代线路尝试可观察；用户能换台或回配置，不会只留下黑屏或永久 loading。错误归因不得把已知源站 503 当作播放器普遍故障。 |
| A11 空列表、坏源与断网缓存 / P0 | 分别准备格式错误 URL、有效但零频道列表、已缓存列表后断网 | 清数据加载坏地址；加载空列表；再次在线成功后断网冷启动 | 每种情形有与原因匹配的空/错误状态、明确文案和恢复操作；零频道不能进入空白播放器；断网时若支持缓存启动，应明确使用缓存并允许播放可用缓存项；若缓存不可用，说明原因且可重新配置。 |
| A12 遥控器焦点与返回优先级 / P0 | 播放中；能够打开节目单、设置、信息条、源选择、错误层 | 逐一打开浮层；在浮层内部左右上下移动；连续按 Back；测试按键映射及快速重复输入 | 任一时刻只有预期的顶层交互接收按键；焦点不进入隐藏/不可见组件、不丢失；Back 按优先级逐层关闭并恢复调用点；最后才按定义退出/返回直播；单次按键不能意外关闭多层或触发底层切台。 |
| A13 可访问性与可读性 / P1 | 目标观看距离和 720p、1080p 逻辑布局可测 | 检查配置页、播放信息、抽屉、设置、空/错状态；用遥控器遍历全部交互项 | 可交互控件有可见焦点和可辨选中/播放状态；状态不只依赖颜色；正文/辅助文字不小于 16sp 且在目标观看距离可读、重要文本不裁切；焦点顺序符合视觉层级；透明 PNG 台标保留原始比例和透明边缘，不被圆角遮切；失败、空、loading 状态各有不同含义。 |
| A14 构建与自动化质量 / P0 | 干净可复现的当前代码状态，依赖可获取 | 执行 `./gradlew.bat :app:assembleDebug`、`./gradlew.bat :app:testDebugUnitTest`、`./gradlew.bat :app:lintDebug`；审阅 lint 报告 | Debug APK 成功生成；单测通过；lint 退出状态与报告问题分别记录（项目配置 abortOnError=false，单看退出码不足以证明无问题）；无新增阻断编译/静态问题。记录命令、退出码、报告路径和 APK 标识。 |

## 3. 必须保留的现有能力与兼容回归

- 主工程 `:app`、Compose for TV / Media3 播放路径及现有 M3U、XMLTV、缓存、设置数据兼容；不得以独立 reconstruction 工程替代主工程或导致两套播放器分叉。
- 初始无源时进入配置；已保存源时恢复上次频道；保存源并播放；手机二维码/LAN 推送并允许任意用户源，不得锁死测试默认地址。
- M3U 重定向处理、频道级 `http-user-agent`（VLC 映射及其他 UA 原样保留并到达实际媒体请求）、IPv4 优先、无 Content-Encoding 头的 gzip EPG 解压、频道合并/多线路尝试、Playlist/EPG 缓存与刷新、Catch-up URL 构造。
- 既有按键能力至少保留其可配置对应：上下换台、左侧节目单、设置入口、OK 信息条、数字连续输入；回看快进/快退及返回直播。新层级不能让旧快捷键失效或冲突。
- 回归数据至少覆盖 ChannelGrouper、M3U UA、重定向、gzip XMLTV、合并线路、空/坏数据、缓存恢复、数字边界及 112 编号映射。自动化适合覆盖解析/映射/状态逻辑；遥控器焦点、首帧、扫码真实提交与观看距离必须另做设备体验检查。

## 4. 验收记录模板

每个 ID 记录：`结果（通过/失败/未验证/延期）`、复现条件与实际步骤、预期/实际结果、证据路径或截图/录屏/日志、设备和 Android 版本、commit/APK 标识、严重度、失败时责任修复项与复验结果。构建、自动化、模拟器体验、目标真机体验分列汇总；环境不可用的项目标记未验证并说明限制，不以源码推断代替运行证据。
