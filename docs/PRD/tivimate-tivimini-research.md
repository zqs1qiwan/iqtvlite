# TiviMate / tivimini 真机设计研究（第一手证据）

> 2026-11-18 在 TR100-G9（192.168.2.245）真机抓取。
> 这是交互重构的唯一视觉真相源。所有实现必须对照本文档的截图证据。

## 1. TiviMate 层级式交互（用户明确要求，真机逐帧验证）

### Level 0 — 全屏播放
- 视频铺满全屏，无任何 UI
- OK → 显示换台信息卡（台标+台名+当前节目+时间+进度+下一节目）
- 上/下 → 换台

### Level 1 — 左键1次：频道列 + 节目单列 + 视频（真机 tm_L0.png）
- **频道列**（左，约 30%）：顶部"卫视频道"标题 + 频道行（编号+台标+台名+当前节目名+进度条）；当前频道高亮 + ▶
- **节目单列**（中，约 30%）：**竖排**时间+节目名（06:20 今日聚焦 / 08:53 经典剧场 青色高亮当前 / ...）；顶部显示当前频道名+组名
- **右上**：当前节目详情卡（节目名+时间区间+进度）
- **视频**（右，约 40%）：透出
- 关键：节目单是**竖列**（tivimini 风格），不是横向网格！

### Level 2 — 左键2次：分组列 + 频道列 + 视频（真机 tm_L1.png）
- **分组列**（最左，约 26%）：收藏频道/全部频道/中央频道/**卫视频道(白底高亮)**/北京频道/其他频道/港澳台/棋牌/电竞/影视/体育
- **频道列**（中，约 32%）：编号+台标+台名+当前节目+进度条，当前频道蓝色+▶
- **视频**（右，约 42%）：完全可见
- 关键：**节目单列收起**，让位给分组列（层级式递进的精髓）

### 层级递进规则（用户原话）
> "全屏播放下 左键呼出基础换台列表 里面陪着epg(竖列节目单) 再按左键展开分组"

即：左键逐级展开，不是一次性全铺开。返回键逐级收起。

### 关键比例
- 分组列默认**隐藏**，左键2次才出现
- Level2 展开分组后：分组26% + 频道32% + 视频42%；节目单列收起
- 用户补充约束："所有展开不应挡住屏幕超过 1/3" —— 我理解为**单次新增的展开层**（分组列约1/4），而非全部面板总和。实现时分组列可做成叠加在频道列左侧的抽屉，宽度约 1/4。

## 2. tivimini 设计（真机截图，用户说"更像 tivimini"）
截图 `Screenshot_20260211_090121.png`：
- **左侧两竖列**：频道列(编号+台标+台名+当前节目，约30%) + 节目单列(时间区间+节目名，约30%)
- 节目单是**竖列**（09:00-10:00 正点财经...），当前节目青色高亮

## 3. 两个金标准的差异与取舍
| 维度 | TiviMate | tivimini |
|---|---|---|
| EPG 形态 | 横向时间轴网格 | 竖列时间+节目名 |
| 展开层数 | 层级式(左键逐级) | 两列常驻 |
| 视频占比 | 播放时100%，展开时顶部预览窗 | 常驻右侧40% |
| 分组 | 单独列，左键2次展开 | 无独立分组列 |

**用户诉求综合**：以 TiviMate 的**层级式交互**为主（左键逐级展开），EPG 用 tivimini 的**竖列简洁**形式，视频尽量透出，展开层 ≤1/3。

## 4. 最终实现方案（待用户确认后执行）
1. **Level 0 全屏播放**：OK=信息卡(台标/台名/当前/下一)，上下换台，数字直跳
2. **Level 1 左键**：频道列(台标+名+当前节目) + 竖列节目单(时间+节目名)；宽度约 55%，右侧视频45%
3. **Level 2 再按左键**：叠加分组抽屉(约1/4屏)，层级递进
4. **右键/菜单**：独立设置抽屉(右侧半透明，宽度≤1/3)
5. 所有面板半透明，视频始终可见

## 7. 延迟调研补充（权威细节，覆盖前面的假设）
### TiviMate 按键映射（操作演示核实）
| 按键 | 播放时 | 说明 |
|---|---|---|
| Up/Down | 换上一/下一频道 | P0 |
| **Right 短按** | **上一个频道（最近两台互切）** | P0，用户诉求5核心 |
| Right 长按 | 显示当前节目信息卡 | |
| **Left 短按** | 打开频道列表/侧栏 | P0 |
| Left 长按 | 频道列表预览模式 | |
| OK 短按 | 打开频道/播放控制面板 | |
| OK 长按 | 当前频道选项菜单 | |
| Back 短按 | 逐层关闭覆盖层 | |
| Back 长按 | EPG浏览时回当前播放器 | P1 |
| 数字键 | 输入频道号跳台（112→112台） | P0 |

**修正**：右键短按必须是"上一台"，不是设置抽屉。设置入口改到最左侧图标栏 ⚙（或菜单键）。

### tivimini 信息横幅（ChannelInfoBanner）
- 位置：**屏幕底部**，垂直滑入/滑出（不是右上）
- 元素：台标80×50、频道序号+名称、当前节目名、直播进度条3dp；右侧可含分辨率/码率/编码
- 5秒自动消失；换台/OK/上下键触发
- 面板 alpha 0.92，顶边圆角18dp

### tivimini 抽屉精确参数
- 频道列 300dp、节目列 300dp+32dp；分组按需展开 150dp；日期按需 110dp
- surface alpha：频道0.92 / 设置0.95；面板圆角18dp，焦点项12dp
- 当前节目#40C4FF浅蓝高亮，过去项0.45透明，未来0.86
- 抽屉spring高刚度无回弹；位移160/140ms；设置侧栏右侧300dp

### TiviMate EPG 点击逻辑（用户诉求5）
- EPG选中频道 → OK = 预览窗显示 → 再OK = 进入全屏播放
- 长按OK = 节目/频道选项（提醒/回看/收藏）
- 这样区分浏览与切台，减少误触

### 刷新逻辑（用户诉求5）
- 播放列表刷新与EPG刷新是**独立两条路径**，各自记最后成功时间
- 启动时更新/周期更新/手动更新分开配置，不互相触发
- 启动回上次频道是P0

### 修正后的最终按键方案
- Left = 频道列表(Level1) → 再Left = 分组(Level2)
- **Right 短按 = 上一台**，Right 长按 = 信息卡
- OK = 信息卡/播放控制；OK长按 = 频道菜单
- 菜单键 或 图标栏⚙ = 设置抽屉
- 数字键 = 直跳频道号
- 上/下 = 换台
