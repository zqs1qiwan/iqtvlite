# 交互金标准 — TiviMate + APTV

> 来源：TiviMate 操作演示 (youtube.com/watch?v=cY3k7Z-mrGU)、APTV 仓库 (github.com/Kimentanm/aptv)、APTV 官网 (aptv.app)、mpvNova/clubTivi 等开源播放器调研。
> 用途：iqtvlite 遥控器交互的唯一验收标准。所有界面必须纯 DPAD 可完成。

## 0. 总纲
- **满屏播放为默认态**，视频 surface 永不销毁（只调布局/透明度）
- UI 按需浮出，半透明浮层视频透出
- 焦点：10-foot 可见反馈（缩放+高亮），刷新后按**稳定内容 ID** 还原焦点（非行号）
- 全程无需触屏；每个操作有即时反馈（加载态/成功态/错误态）

## 1. 满屏播放态（默认）
| 元素 | 要求 | 状态 |
|---|---|---|
| 视频铺满底层 | 常驻，UI 隐藏时纯净画面 | ✅ |
| 换台信息卡 | 右上浮出 3-5s 自动隐藏：频道号/台标/名称 + 当前节目名 + 时间区间 + 进度 | ✅ |
| 底部状态条 | 频道名/播放状态，缓冲时明确提示 | ✅ |
| 时钟 | 顶栏，每分钟更新 | ✅ |

**按键映射（MUST）**
- 上/下（或 CH+/CH-）= 换台 ✅
- 左 = 打开频道列表；右 = 打开 EPG 网格 ✅
- OK = 打开/关闭主 UI 浮层 ✅
- 返回 = 无浮层时二次确认退出；有浮层时逐层关闭 ✅
- 数字键 = 频道号跳转（连续输入组合） ✅
- 菜单键/长按 OK = 当前频道上下文菜单（收藏/隐藏/锁定/画面比例） ✅（长按菜单已实现，菜单键待确认）

## 2. 频道列表浮层
| 元素 | 要求 | 状态 |
|---|---|---|
| 左侧分组栏 | 全部/收藏/最近/各分组，chip 样式 | ✅ |
| 频道行 | 编号 + 台标(撑满深色容器) + 频道名 + 当前节目名 + (仅当前播放)进度条 | ✅ |
| 焦点态 | 圆角高亮 + 缩放 + ▶ 播放标记 | ✅ |
| PiP 预览 | 焦点频道静音实时预览（APTV 金标准） | ✅ |
| 搜索 | 顶部输入框，输入即过滤 | ✅ |

**按键**：上下移动焦点换 PiP；OK 播放选中频道并关闭浮层回满屏；返回关浮层；长按 OK 上下文菜单。✅

## 3. EPG 时间轴网格（护城河功能）
| 元素 | 要求 | 状态 |
|---|---|---|
| 左列频道 | 台标+名称，随网格纵向滚动 | ✅ |
| 横向时间轴 | 30min 刻度，可左右滚动查看多时段 | ✅ |
| 节目块 | 标题+时间，当前节目高亮+进度 | ✅ |
| now 线 | 当前时刻竖线 | 待核实 |
| 节目详情 | OK 长按弹出详情（名称/时间/简介/回看入口） | 部分 |

**按键**：上下切频道行，左右滚动时间轴，OK 播放选中节目（当前节目→切该频道；过去节目且有 catchup→回看）。✅
