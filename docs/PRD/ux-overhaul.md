# PRD — TiviMate 风格交互重构（v2.0 UX Overhaul）

> 用户反馈 v1.9.1「交互太灾难」。本 PRD 是交互重构的唯一真相源。
> 金标准：TiviMate（Android TV）+ tivimini（用户认可，源码已分析）+ Apple TV 视觉质量。
> 状态：APPROVED（用户全权批准）| 2026-11-18

## 0. 七条用户诉求 → 验收标准
1. **Logo**：透明 PNG 直接显示，无边框无底色；换台信息卡也有台标 → ✅ 已完成真机验证
2. **设置/节目单分离**：OK 不是开大面板；呼叫设置与呼叫节目单是两个独立逻辑；日常就是换台+看节目单
3. **照 tivimini**：OK=信息横幅，左=频道/节目单抽屉，右=设置抽屉，两者独立
4. **换台信息**：台名+台标+正在播放+接下来播放 → ✅ 已完成
5. **遥控器与启动配置**：数字键直跳（112→112台）、上一台快捷键、启动回上次台、遥控器按键可配置、刷新时机可配置、点击节目行为可配置
6. **视觉/品牌**：Apple TV 质量，全局统一
7. **侧边半透明**：所有设置/面板在屏幕一侧，半透明，不挡节目内容

## 1. 交互模型（tivimini 金标准 + 用户修正）

### 1.1 默认态（日常）
满屏播放，**无任何 UI**。用户日常就是看着电视，用上/下换台。

### 1.2 按键映射（重构后）
| 按键 | 行为 | 来源 |
|---|---|---|
| 上 / 下 | 换上一/下一频道（默认；可在设置改） | TiviMate + tivimini |
| 左 | 打开**频道/节目单抽屉**（独立） | tivimini |
| 右 | 打开**设置抽屉**（独立，半透明侧栏） | tivimini + 用户诉求 |
| OK | 显示/隐藏**换台信息横幅**（台标/台名/当前/下一） | tivimini + 用户诉求 |
| 返回 | 逐层关闭：抽屉→信息横幅→（二次）退出 | tivimini |
| 数字键 | 直接输入频道号跳台：输 112 → 1.5s 后跳 112 号台；Back 清空；屏显缓冲 | 用户诉求 + TiviMate |
| 菜单键 | 打开设置抽屉（同右键） | TiviMate |
| 上一个台 | 快捷键（默认长按 OK 或 CH_PREV，可配置） | 用户诉求 |
| 信息键 | 显示信息横幅（同 OK） | TiviMate |

### 1.3 两个独立抽屉
- **频道/节目单抽屉（左）**：半透明侧栏，含分组/频道列表/EPG 切换；视频始终透出
- **设置抽屉（右）**：半透明侧栏，分分类的设置项；不再是全屏 Activity
- 两者**互斥**：打开一个自动关闭另一个；各有独立焦点与返回逻辑

### 1.4 信息横幅（OK 触发）
台标（透明 PNG）+ 台名 + 频道号 + 当前节目名 + 时间区间 + 进度 + 下一节目名。5s 自动隐藏。

## 2. 设置项清单（TiviMate 意义驱动，用户诉求 5）

### P0（第一批必做）
| 分类 | 设置项 | 默认 | 意义 |
|---|---|---|---|
| 遥控器 | 上/下键动作 | 换台 | 适配遥控器习惯 | ✅ |
| 遥控器 | 左/右键动作 | 左=频道单/右=设置 | 高频操作分配 |
| 遥控器 | OK 动作 | 信息横幅 | 一键看详情 |
| 遥控器 | 上一个台快捷键 | 右键短按 | 快速回前一个频道 | ✅ |
| 启动 | 启动时行为 | 回到上次频道 | 用户诉求 | ✅ |
| 数字跳台 | 启用数字直跳 | 开 | 输 112→112台 | ✅ |
| 播放列表 | 自动刷新时机 | 启动+每12h | TiviMate 逻辑 | ✅ |
| EPG | 自动刷新时机 | 启动+每6h | TiviMate 逻辑 | ✅ |
| EPG | 点击节目行为 | 播放/回看可选 | 用户诉求 | ✅ |

### P1（第二批）
| 分类 | 设置项 | 默认 | 意义 |
|---|---|---|---|
| 遥控器 | 各键短按/长按分别配置 | — | TiviMate 完整映射 |
| EPG | 显示天数 | 7天 | 节目单跨度 |
| EPG | 源优先级 | 按添加顺序 | 多源合并 |
| 播放 | 缓冲策略 | 低延迟 | 起播速度 |
| 播放 | 解码器偏好 | 硬解优先 | 兼容性 |
| 外观 | 信息横幅显示时长 | 5s | 停留时间 |
| 外观 | 抽屉透明度 | 85% | 不挡视频 |
| 频道 | 隐藏/排序/自定义分组 | — | 已有，纳入设置抽屉 |

### P2（第三批）
多语言、主题细节、播放统计展示、备份增强

## 3. 视觉/品牌（Apple TV 质量，用户诉求 6）
- 全局设计 token：近黑底 + 青蓝强调 + 三级灰文字（已有基础，继续统一）
- 侧栏半透明（85-90%），视频透出（用户诉求 7）
- 焦点态：柔和放大 + 高亮，无硬边框
- 品牌资产：重做 app icon / banner / logo，统一视觉语言
- 所有抽屉、弹层、信息卡圆角/间距/字重统一

## 4. 迭代顺序
- **UX-1**: 按键映射重构（OK=信息、左=频道单、右=设置抽屉）+ 两个独立半透明抽屉骨架
- **UX-2**: 数字直跳 + 上一个台 + 启动回上次台
- **UX-3**: 设置抽屉填充 TiviMate P0 配置项（遥控器/刷新/启动/节目点击），可配置且真正生效
- **UX-4**: 视觉/品牌统一（Apple TV 质量）
- 每步真机验证 + CI 出包

## 5. 金标准来源
